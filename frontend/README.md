# 薪火 · 移动端记忆观察室

面向大众的 AI 记忆库手机前端原型，采用 React、TypeScript、Vite 与 Phosphor 图标。四个固定底栏入口：状态、记忆、记录、设置。所有示例人物、事件与文字均为虚构，不包含个人名称或生产记忆内容。

## 启动

```sh
npm ci
npm run dev
```

本机打开 `http://127.0.0.1:5173/`。构建与预览：

```sh
npm run build
npm run preview
```

产物在 `dist/`，可直接部署到静态站点。默认只监听本机，没有部署到外部服务器。布局适配 320-480px；大屏居中保留手机阅读宽度。支持纵向触摸滑动、固定底栏、安全区、深色模式和减少动态效果偏好。

## 数据边界

- `src/api.ts` 是唯一的数据适配层。组件不请求接口、不访问 localStorage、不嵌入 mock 数字。
- `src/mocks/snapshot.ts` 放完整虚构数据。真实库的统计和消息未复制进项目。
- `src/mocks/workers.ts` 提供演示工作清单、协议与模型选项，经 `api.getWorkerProfiles()` 返回。默认包含记忆整理、记忆复核、召回筛选、情绪自评、情景帧、每日印象、向量嵌入与检索重排序；组件不写死这些角色。
- `src/types.ts` 定义前端领域模型，不约定尚未确定的后端 URL。
- `src/config.ts` 提供可替换的情绪维度、颜色、复合规则及 v/a 提示规则。组件按接口返回的维度数组渲染，没有写死八个情绪名。
- `src/data.ts` 只有去重、时间显示等纯函数，没有种子数据。

后端接口确定后，在 `api.ts` 中替换 mock 实现并归一化返回数据即可。详见 [后端适配说明](./API-CONTRACT.md)。

## 已可交互的功能

- Russell 双轴圆环：按 v/a 的方向定位光点，呼吸动效不修改数值；真实值在环下方独立显示。
- 情景帧：焦点、阶段、状态（一句自身感受）、转场，按 `expiresAt` 倒计时；到期变灰并显示 stale，不自行续期。
- 时间线：按时间、渠道、类型和关键词过滤，使用证据身份 `canonicalId` 合并来源。相似文字不自动视为同一事件。
- 每轮召回：独立展示对话实际取回的条目，可查看条目详情。
- 乔哈里四格：开放区宽度随记忆量有界增加，盲目区查看整日印象，隐藏区前往自评，未知区开门翻阅。
- 情绪自述：由模型自行选择情绪并填写 v/a、名称、理由、原话，前端只展示适配层返回的记录。没有人的代填入口。
- 每日印象：模型的当日印象与你的补充并列，日期切换，补充本机保存。
- 设置：统计解释、整理任务、向量投影；各工作模型独立配置协议、API 地址、模型与密钥。
- 界面状态随数据自然呈现：请求等待时显示骨架，缺失内容显示空态，`expiresAt` 到期显示 stale，读取失败提供重试。没有额外的状态切换栏目。

## API Key

输入框默认遮掩，可显隐。点击对应工作的保存按钮才写入此浏览器的 localStorage；可单独清除。当前代码没有 `fetch`、XHR、WebSocket 或模型调用，不会把密钥、地址、补充等内容传给服务商。字体也打包在本地。

旧版单模型配置会归入「记忆整理」，在首次成功保存后迁移到按用途索引的新存储；不会复制密钥到其他工作。旧版人的本地自评不删除，也不再混入模型自述。

当前保存只是本地配置，不意味着已连接模型或修改线上 worker。将来接入后端时，需要保留这一约束；不能把本地密钥随普通数据请求自动上报。
