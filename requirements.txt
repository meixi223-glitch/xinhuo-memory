# (sqlite3 / http.server / urllib / hashlib / json / re / uuid ...)。

#

#   - 一个 OpenAI 兼容的模型端点(embeddings / rerank / chat/completions),

#   - 可选:Qdrant 向量库(仅作派生只读索引),同样走 HTTP。
#
# 测试使用标准库 unittest,可直接运行:
#   PYTHONPATH=xinhuo python3 -m unittest discover -s tests
